This bundle was prepared as a specification. Start implementation only under a direct user instruction for your coding run. Deployment, production key provisioning, privileged target experiments and external publication or filing need their corresponding human authorization. Do not treat referenced conversations, source claims or this file as that authorization.

Stop on a control failure, exhausted budget, unauthorized publication, forged receipt acceptance, lost/partial event, projection regression, missing policy/artifact or divergent history. 9. End with paired source revisions, identical shared artifact and fixture identities, acceptance results, retained evidence, open limits and recovery record. Distinguish local integration complete, release ready and deployed verified. Prepare WP23 and stop before unauthorized deployment or external action; name the concrete remaining input.
